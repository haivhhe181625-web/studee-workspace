|---|---|---|---|---|

| `cefrRange.ceiling` | String (enum) | ✗ | null | Như floor. Range [floor, ceiling] = learner band nằm đây mới eligible. |
| `program` | String (enum) | ✗ | null | Enum: PROGRAM_KEYS (`general|ielts|toeic|...`). Null = universal (any program). Resolver match target.program. Live-safe (NOT structural). |

| `sourceCourseSlug` | String | ✗ | null | Course slug generated map came from. Null = hand-authored. For health tracking / regenerate. |
| `createdAt` | Date | ✓ | (auto) | Mongoose timestamps. |
| `updatedAt` | Date | ✓ | (auto) | Mongoose timestamps. Updated on every doc mutation. |
| `__v` | Number | — | (auto) | Mongoose versioning (strip on DTO return). |

## MapNode (embedded in nodes[])

| Field | Kiểu | Bắt buộc | Default | Ghi chú |
|---|---|---|---|---|
| `nodeKey` | String | ✓ | — | Stable globally unique ID per template (e.g., `p1:l1`, `ielts-fnd:p2:m3:l4`). Ref by prerequisites/edges. Never renumber once published. |
| `nodeKind` | String (enum) | ✓ | — | Enum: `CORE|PRACTICE|CHECKPOINT|REMEDIATION|SIDE_QUEST`. Structural role. |
| `activityType` | String (enum) | ✓ | — | Enum: `VIDEO_LESSON|MCQ_QUIZ|FLASHCARD_DECK|IPA_DRILL|CAT_TESTLET|WRITING_TASK|SPEAKING_TASK|SPEAKING_CHATBOT|CONTENT`. Pluggable engine. |
| `activityRef` | Object | ✗ | {} | Ref to content (lesson/deck/IPA section). Adapter resolves. KHÔNG authorable (FE chỉ show, BE có thể preset). |
| `activityRef.refCollection` | String | ✗ | null | Target collection (e.g., `lessons|decks|ipa_sections`). Adapter-specific. |
| `activityRef.refId` | ObjectId | ✗ | null | ObjectId of content doc. Adapter lookup. |
| `activityRef.slug` | String | ✗ | null | Slug for UI display (e.g., lesson title). |
| `config` | Mixed (Object) | ✗ | {} | Engine-specific params (shape owned by adapter). For MCQ: `{itemIds:[...], passRatio:0.8, itemCount:5}`. Server-side only (strip learner). |
| `config.itemIds` | Array[String] | ✗ | [] | AssessmentQuestion IDs assigned to MCQ_QUIZ node. Validate: mcq, active, centerId:null. Empty MCQ allowed DRAFT, blocked PUBLISH. |
| `config.itemCount` | Number | ✗ | null | Optional hint for item count (matched template health check). |
| `config.passRatio` | Number | ✗ | 0.8 | Mastery pass threshold (0–1). Used learner grading. |
| `config.theory` | String (Markdown) | ✗ | null | CONTENT node lý thuyết (server-only, strip learner). Rich text / markdown. |
| `skillTag` | String (enum) | ✗ | null | Enum: ALL_CATEGORIES (e.g., `listening|reading|writing|speaking|grammar|vocabulary|...`) or null. Drives mastery skip & remediation targeting. |
| `subskillTags` | Array[String] | ✗ | [] | Free-string array (KHÔNG ràng SUBSKILLS constant). Taxonomy node-level (e.g., `present-simple`, `daily-routines`, `pronunciation-tips`). |
| `prerequisites` | Array[String] | ✗ | [] | NodeKeys must clear before this node (locked by gatePolicy). Gating engine chạy đây, KHÔNG edge. |
| `gatePolicy` | String (enum) | ✗ | `HARD` | Enum: `HARD|SOFT|NONE`. HARD = must master. SOFT = test-out skip (Phase 2). NONE = always open. |
| `position` | Object | ✗ | {row:0,col:0} | Canvas position (for visual rendering). Live-safe (can reposition without 409). |
| `position.row` | Number | ✗ | 0 | Row (0-indexed). |
| `position.col` | Number | ✗ | 0 | Column (0-indexed). |
| `masteryThreshold` | Number | ✗ | 0.8 | Mastery cutoff [0,1]. COMPLETED → MASTERED when score >= threshold. Live-safe. |

## Edge (embedded in edges[])

| Field | Kiểu | Bắt buộc | Ghi chú |
|---|---|---|---|
| `from` | String | ✓ | Source nodeKey. Must exist in nodes[]. |
| `to` | String | ✓ | Target nodeKey. Must exist in nodes[]. |

**Constraint:** For each edge `a→b`, node `b.prerequisites` must contain `a` (mirror check). Edges for visual only; gating reads prerequisites.

## DTO Mapper (toDto method + admin-api response shape)

Admin endpoints trả DTO (KHÔNG raw Mongoose doc):

```javascript
{
  "id": String(doc._id),
  "templateKey": doc.templateKey,
  "version": doc.version,
  "status": doc.status,
  "cefrRange": doc.cefrRange,
  "program": doc.program,
  
  // Counts for UI summary
  "nodeCount": doc.nodes.length,
  "edgeCount": doc.edges.length,
  
  // Health indicator for admin
  "itemsHealth": [
    {
      "nodeKey": "...",
      "itemCount": doc.nodes[i].config.itemIds.length,
      "minRequired": 5,  // constant MIN_ITEMS
      "healthy": itemCount >= minRequired
    }
  ],
  
  // If pinned learner query results (optional, expensive)
  "pinnedLearners": true|false,  // Boolean flag (1 doc = learners > 0)
  
  // Detail only (list omit for perf)
  "nodes": [...],
  "edges": [...],
  
  // ISO timestamp (NOT milliseconds from Mongoose default toJSON)
  "updatedAt": doc.updatedAt.toISOString()
}
```

**Learner surface DTO** (separate service `learning-map.service.js:61-70`):
- Strip `nodes[].config.itemIds`, `nodes[].config.answerKey` (mapped to `config` only server-side).
- Strip `nodes[].config.theory` (CONTENT node server-only).
- Trả `nodes[]` (structure only), `nodeStates` (learner progress from LearnerPath).

## LearnerPath snapshot (related, NOT part of CourseMapTemplate)

`LearnerPath` ref template:

```javascript
LearnerPath.segments = [
  {
    templateKey: "course-ielts-foundation",
    version: 1,  // PINNED to template v1 at assignment time
    // ... learner's path snapshot (phases/modules/lessons)
  }
]
```

**Design principle:** LearnerPath snapshot (deep-copy structure at assignment time) pinned to (templateKey, version). Admin edit template → learner cũ KHÔNG retroactive; learner mới (tạo path) use published latest of key.

## Index strategy

**Primary:**
- `{ templateKey: 1, version: 1 }` unique

**Supporting (optimize queries):**
- `{ generated: 1 }` — filter out generated (exclude from template-resolver auto-pick)
- `{ sourceCourseSlug: 1, generated: 1 }` — course→map view health (find generated per source)
- `{ status: 1 }` — filter draft/published/archived
- `{ program: 1 }` — resolver match program
- `{ "cefrRange.floor": 1, "cefrRange.ceiling": 1 }` — resolver band match (optional, CEFRRANGE only [5] docs)

## Validation rules (implemented in map-template-validate.js)

- **templateKey:** non-empty string, unique per version (E11000 catch).
- **version:** positive integer.
- **status:** enum {draft, published, archived}.
- **cefrRange:** floor/ceiling both in CEFR_LEVELS or both null (not mixed).
- **program:** enum PROGRAM_KEYS or null.
- **nodes[].nodeKey:** required, non-empty, unique within template, no duplicates.
- **nodes[].nodeKind:** required, enum NODE_KINDS.
- **nodes[].activityType:** required, enum ACTIVITY_TYPES.
- **nodes[].skillTag:** if specified, must be in ALL_CATEGORIES; null OK.
- **nodes[].subskillTags:** free-string array, no ràng SUBSKILLS (taxonomy node-level).
- **nodes[].prerequisites:** all items must exist as nodeKey, no self-ref.
- **nodes[].gatePolicy:** enum GATE_POLICIES.
- **nodes[].masteryThreshold:** number [0,1].
- **nodes[].config.itemIds:** if MCQ_QUIZ node, must be array of AssessmentQuestion._id (async):
  - Item type = `mcq`
  - Item status = `active`
  - Item centerId = null (shared bank only)
  - If invalid item → error path `nodes[i].config.itemIds[j]`
  - Empty array allowed DRAFT; blocked PUBLISH.
- **edges[].from/to:** must reference existing nodeKey in template.
- **Edges mirror prerequisites:** for edge `a→b`, node `b` must have `a` in prerequisites (gating engine dependency).
- **Cycle detection:** no circular prerequisite paths (warn DRAFT, block PUBLISH).

## Structural signature (canonicalized for 409 detection)

```javascript
structuralSignature(doc) {
  const canonical = {
    nodes: doc.nodes
      .sort((a, b) => a.nodeKey.localeCompare(b.nodeKey))
      .map(n => ({
        nodeKey: n.nodeKey,
        nodeKind: n.nodeKind,
        activityType: n.activityType,
        skillTag: n.skillTag,
        subskillTags: [...n.subskillTags].sort(),  // as set
        prerequisites: [...n.prerequisites].sort(),  // as set
        gatePolicy: n.gatePolicy,
        // F18: config.skill (CHECKPOINT only) is structural
        ...(n.nodeKind === 'CHECKPOINT' && n.config?.skill ? { skill: n.config.skill } : {}),
        // F11: flip itemIds empty↔nonempty = structural (curated↔simulator)
        itemIdsEmpty: n.activityType === 'MCQ_QUIZ' ? (n.config?.itemIds?.length === 0) : undefined
      })),
    edges: [...doc.edges]
      .map(e => `${e.from}>${e.to}`)
      .sort()
  };
  
  return JSON.stringify(canonical);
}

// updateTemplate uses this to detect structural change:
// IF stored.status === 'published' && structuralSig(incoming) !== structuralSig(stored)
//   → 409 TEMPLATE_STRUCTURAL_LOCKED
```

**Live-safe (NOT structural):**
- position (row/col reorder OK)
- masteryThreshold (pass cutoff adjust OK)
- cefrRange (enroll future only, learner cũ pinned)
- program (fallback match adjust OK)
- config (except CHECKPOINT.skill + itemIds empty/nonempty flip)
- updatedAt (timestamp auto)
